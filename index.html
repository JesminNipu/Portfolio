Research & Development

Research Projects

Python TensorFlow SCNN OpenCV

Simplistic CNN (SCNN) Potato Blight Disease Detection

Developed a lightweight Simplistic Convolutional Neural Network (SCNN) to address computational memory and training-time drawbacks of traditional multi-layer CNNs. Engineered a compact architecture featuring 3 progressive hidden layers (16, 16, 32 kernels) optimized for low-resource agricultural deployment.

95.69% classification accuracy on real-world potato leaf blight datasets
Python CNN TensorFlow TensorBoard

Smart Device Potato Blight Detection

Developed a customized CNN for real-time mobile detection of potato early blight, late blight, and healthy leaves. Built a complete data preprocessing and training pipeline optimized for smartphone and resource-constrained device deployment, using layer-by-layer TensorBoard optimization.

96.09% classification accuracy using fine-tuned hyperparameters
PyTorch VGG16 Transfer Learning OpenCV

Potato Blight Classification via VGG16 Transfer Learning

Implemented a VGG16 transfer learning model pretrained on ImageNet for potato leaf blight disease classification. Built an optimized feature extraction and training pipeline tailored for high-accuracy plant pathology diagnosis on limited datasets.

96.88% classification accuracy on a custom image dataset
PyTorch TensorFlow ResNet EfficientNet

Comparative Plant Pathology Classification

Built a high-resolution image preprocessing and data augmentation pipeline to standardize grape and potato leaf disease datasets (blight, downy mildew). Fine-tuned CNN, ResNet, and EfficientNet architectures using transfer learning for multi-crop disease classification.

CNN: 94%  |  ResNet: 96%  |  EfficientNet: 97%
Java Android SDK PHP Google Maps API
